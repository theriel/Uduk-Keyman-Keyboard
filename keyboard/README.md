Uduk keyboard
==============

Description
-----------
DESCRIPTION This is the Keyman edition of the Uduk keyboard. It's based on the standard US keyboard layout, with additional easy access to the slash, ŋ, and the ʼ  symbol. Additional letters are found by long-pressing in the mobile version.  Future versions will include a Windows version as well.
